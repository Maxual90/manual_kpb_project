Project Summary — College Alumni Connect

I am building a College Alumni Connect website using HTML, CSS, JavaScript, PHP, MySQL, and XAMPP.

Environment
Using XAMPP
Database: firstdb
Table: students
MySQL username: root
MySQL password: empty ("")
Host: localhost
students table

The table has these columns:

admin_no    PRIMARY KEY    int(11)
name                       varchar(25)
email                      varchar(25)
batch                      varchar(25)
course                     varchar(25)
pass                       varchar(25)

Current project assumption:

email is used as the login username.
pass is used as the login password.
Passwords are currently stored as plain text. This is only for the current simple project stage; later it should be changed to password_hash() / password_verify().

2. Current login.php

The current login PHP is:

<?php


// Database connection
$host = "localhost";
$user = "root";
$password = "";
$database = "firstdb";


$conn = new mysqli($host, $user, $password, $database);


// Check connection
if ($conn->connect_error) {
    die("Database connection failed: " . $conn->connect_error);
}


// Check that the form was submitted
if ($_SERVER["REQUEST_METHOD"] == "POST") {


    $email = $_POST["email"];
    $pass = $_POST["pass"];


    // Check if user exists
    $sql = "SELECT * FROM students WHERE email = ? AND pass = ?";


    $stmt = $conn->prepare($sql);
    $stmt->bind_param("ss", $email, $pass);
    $stmt->execute();


    $result = $stmt->get_result();


    if ($result->num_rows == 1) {


        // Login successful
        header("Location: feed.php");
        exit();


    } else {


        // Login failed
        echo "<script>
                alert('Invalid username or password');
                window.location.href='login.html';
              </script>";
    }


    $stmt->close();
}


$conn->close();


?>

The Connect button currently only works visually using JavaScript.

Current JavaScript:

function connect(button){


    if(button.classList.contains("connected"))
    {
        button.classList.remove("connected");
        button.innerHTML="Connect";
    }


    else
    {
        button.classList.add("connected");
        button.innerHTML="✓ request sent";
    }


}

Important: Connection requests are NOT currently saved in MySQL. The button only changes visually.

7. Important next improvements

The project is currently at the stage where registration → login → database-driven feed can be developed further.

Recommended next steps:

A. PHP sessions

After successful login, use:

session_start();

and save the logged-in user's information.

This will allow the application to know who is currently logged in.

Then the feed can avoid showing the logged-in student themselves.

For example:

Logged-in user: Rahul


Feed:

Rahul     → DON'T SHOW
